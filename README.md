# Used Car Price Prediction

## О проекте

Цель проекта — построить модель для оценки стоимости подержанного автомобиля по его характеристикам.

Выбрал этот датасет по нескольким причинам:
1. Признаки разных видов: числовые, категориальные и составные текстовые признаки.
2. Знакомая и прикладная тема
3. Сложная и интересная для исследования природа данных 

## Гипотезы

1. Автомобили без зарегистрированных аварий имеют более высокую медианную цену.
2. Добавление признаков из `engine` уменьшит ошибку модели.
3. `horsepower` войдёт в число наиболее важных признаков случайного леса.
4. Random Forest покажет меньшую ошибку, чем линейная регрессия.
5. Обучение на `log(price)` уменьшит ошибку линейной регрессии.
6. Электромобили и гибриды имеют более высокую медианную цену, чем бензиновые автомобили.

## Результаты

- гипотеза 1 подтвердилась;
- гипотеза 2 не подтвердилась;
- гипотеза 3 подтвердилась;
- гипотеза 4 подтвердилась;

- гипотеза 6 подтвердилась.
