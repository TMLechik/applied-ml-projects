# Постановка задачи
Цель проекта — построить модель, которая оценивает стоимость подержанного автомобиля по его характеристикам.

1. Объект — один автомобиль;
2. Признаки — марка, модель, год, пробег, двигатель, коробка передач и другие характеристики;
3. Целевая переменная — цена автомобиля;
4. Тип задачи — регрессия;

Предполагаемое применение — предварительная оценка рыночной стоимости автомобиля.
